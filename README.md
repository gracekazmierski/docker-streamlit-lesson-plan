# Titanic Survival Predictor (Docker + Streamlit Workshop)

This repository contains all materials for the Docker + Streamlit hands-on lesson.
Students clone the repo, run a Streamlit app locally, customize it, and finally
containerize it using Docker.

The machine learning model (Random Forest) is trained locally using Python 3.13 to ensure full compatibility with the Docker image and
the Streamlit app.

---

## Project Structure
```
├── app.py # Streamlit application
├── train_model.py # Script to train and export ML model
├── train.csv # Titanic dataset
├── ml-model.pkl # Trained model (generated by train_model.py)
├── requirements.txt # Streamlit + sklearn dependencies
└── Dockerfile # Container definition
```

---

## 1. Create and Activate a Virtual Environment

### Windows
```bash
python -m venv env
.\env\Scripts\activate
```
### macOS | Linux
```
python3 -m venv env
source env/bin/activate
```

## 2. Install Dependencies

```
pip install -r requirements.txt
```

## 3. Train the Model (Optional for Students)
If you want to regenerate the model from scratch:
```
python train_model.py
```
This will output:
```
Validation Accuracy: 0.83–0.86
Saved titanic-model.pkl
```

## 4. Run the Streamlit App Locally
```
streamlit run app.py
```
Visit:
```
http://localhost:8501
```
You can now interact with the Titanic Survival Predictor and modify the UI as part of the workshop.

## 5. Build the Docker Image
From the project root:
```
docker run -p 8501:8501 titanic-app
```
Then Open:
```
http://localhost:8501
```
The Streamlit app is now running *inside* Docker.

## 6. Exercises for Students

1. Modify the Streamlit UI
2. Add new input fields
3. Display model probabilities or charts
4. Rebuild the Docker image with your changes
5. Add a second page using st.sidebar
6. Explore how Docker layers change when modifying code

## Enjoy the Workshop!

Feel free to experiment, break things, rebuild them, and explore how Docker and
Streamlit work together to deploy machine learning applications.
